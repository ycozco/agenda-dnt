# Referencias odontológicas

Estos archivos se copian desde `prototype/assets/images/dental-reference` para que la
versión v2 tenga una fuente única de recursos visuales. Son referencias educativas y de
interfaz: no contienen pacientes del sistema, no representan historias clínicas y no
sustituyen los iconos oficiales que el Colegio Odontológico del Perú autorice para
producción.

La catalogación completa está en `dental-reference-catalog.json`. Antes de publicar un
recurso, conservar su licencia, atribución y contexto de uso.
